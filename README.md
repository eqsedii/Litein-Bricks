# Litein Bricks

Website for Litein Bricks, quality red clay bricks in Litein, Kericho County.

```
index.html          Landing page with the four options
delivery.html       Delivery prices and order estimate
why-us.html         Why choose Litein Bricks
how-to-order.html   Ordering steps
contact.html        Contact details
css/styles.css  Styles and colour tokens (top of file)
js/main.js      Mobile menu and order estimate
assets/         logo.png, background.mp4 (shown at 40% opacity), poster.jpg
```

Open `index.html` in a browser to preview. To publish with GitHub Pages: Settings > Pages > deploy from the `main` branch, root folder.
